# Paranoidal-Alien-biomes — инструменты сопровождения

Текущее имя мода: **`Paranoidal-Alien-biomes`**, версия **9.8.6**.
Прежнее имя `Alien-biomes-Reforged` остаётся в истории, путях к старым резервным
копиям и в запрете одновременного включения двух версий (`!` в dependencies).
Идентификаторы прототипов, настройки `alien-biomes-*` и remote-интерфейс
`alien-biomes-reforged` не переименованы. Миграции для переименования не добавлены;
существовавшая миграция upstream оставлена без изменений.
Вся графика после пользовательского сжатия сохранена побайтно. Хеши результата
в `data/tile-merge-report.json` относятся к **несжатому выходу генератора 0.8.6**,
а не к текущим оптимизированным PNG; отчёт не перезаписывается.
Проверки переименования и интеграций сборки: `data/report-9.8.6.md`.

Эта папка — всё, что нужно, чтобы понять, проверить, пересобрать и обновить мод.
Игра её не читает. Отчёты фиксируют, относительно какого эталона измерены ошибки.

## Зачем существует мод

Alien Biomes (Earendel, CC0) хранил каждый цветовой вариант почвы, песка, травы,
вулканической земли, дюн и лавы отдельной текстурой. Рисунок у вариантов похож,
но отличается также локальной окраской и контрастом; каждая текстура занимает место в атласе спрайтов —
в сумме больше 2 ГиБ несжатого RGBA только у этого мода.

Reforged объединяет Alien Biomes 0.7.4 и Alien Biomes Graphics 0.7.1 в один мод и
рисует цветовые варианты из общих **тинт-матриц**: одна светлая текстура на семейство
плюс цвет `tint` в прототипе. Движок умножает текстуру на `tint` при отрисовке,
поэтому атлас хранит одну картинку вместо двенадцати.

Принципы, которые нужно сохранять при любых изменениях:

- **Имена прототипов и настроек upstream не меняются** (тайлы, декоративы, деревья,
  `alien-biomes-*`): сохранения и интеграции других модов продолжают работать.
- **Код upstream правится минимально.** Своя логика — в собственных файлах
  (`prototypes/reforged/`, файлы, которых нет у upstream); в код upstream она
  подключается короткими правками из `patches.py`. Тогда новую версию Alien Biomes
  можно накатить командой `reforge.py code`, а не вручную.
- **Готовые PNG не перегенерируются без нужды.** Новые основы 0.8.6 сохранены в RGBA8
  с `compress_level=0`, без палитризации и оптимизаторов. Финальное сжатие выполняет
  пользователь; перед ним нужно сохранить эталон PNG и после сравнить пиксели.
- **Каждый шаг проверяется**: цифрами (PSNR/SSIM), превью «оригинал | результат | разница»,
  dump'ом движка и сравнением с оригиналом.

## Как устроены тинт-матрицы

Движок рисует `premultiplied(текстура) × tint`. Для семейства одинаковых по рисунку
изображений `X_c` (c — цвет) ищется матрица `M` и цвета `t_c`, минимизирующие
`Σ ||X_c − t_c·M||²` — это разложение ранга 1 (главный собственный вектор матрицы
Грама). Все расчёты идут в premultiplied RGB, как у движка.

Варианты, которые строит `abtint.py build`:

| Модель | Смысл |
|---|---|
| `grey` | одна серая матрица, цвет целиком в `tint` |
| `rgb` | своя матрица на каждый канал (точнее, если оттенок пятен различается) |
| веса `plain` / `equal` / `minimax` | обычная ошибка / равный вклад цветов / итеративно подтягивает худший цвет |
| группы (`plan-k2`) | цвета семейства делятся на 2 группы по лучшему разбиению, у каждой своя матрица |
| `additive` | 2 слоя: нетинтованная основа + аддитивное тинтованное свечение (лава-декали) |

`tint` может только затемнять, поэтому матрица нормируется в светлую область
(самый яркий цвет получает `tint` около 1).

`select.py` выбирает для каждого семейства вариант с минимумом файлов, у которого
худший цвет даёт PSNR ≥ 36 дБ и SSIM ≥ 0.95; если таких нет — лучший из вариантов
с не более чем двумя файлами для декоративов. **Начиная с 0.8.6 для тайлов разрешена
только одна группа с одним файлом**, даже если порог качества не достигнут. Планы k2
сохранены для исторических экспериментов, но установить их тайлы через `matrices` нельзя.
Для тайлов `additive` не используется: у основного рисунка нет произвольных слоёв.

Исторический результат (0.8.0): 556 текстур → 84 матрицы. Ниже порога (принятая потеря):
трава grass-1/2, volcanic heat-3/4, лава-декали. Подробно — `data/selection.md`,
все варианты — `data/compare-variants.md`, отчёт 0.8.0 — `data/report-0.8.0.md`.

В **0.8.6** объединены все 13 пар g1/g2 тайлов: **28 → 15 основ**, всего матриц
тайлов и декоративов **84 → 71**. 128 tint переподобраны, ещё 16 (sand-1 и heat-1)
сохранены. Обе настройки атласа используют одинаковые основы и tint.

`merge_tiles.py` строит компромиссные основы по **текущему Reforged**, не по upstream:
поканальная смесь двух нормированных основ, поиск SLSQP по худшей ошибке цвета,
ограничение tint 0…1, проверка после округления PNG и четырёх знаков tint. Учитываются
все используемые кадры, а не пустое место листа. Повторяющиеся пары пикселей объединены
с точными весами. Каждая новая основа сравнивается также с обеими старыми основами;
выбирается вариант с меньшей максимальной MSE, без заявления о глобальном оптимуме.
Прозрачность в используемых кадрах новой смеси заменена непрозрачным premultiplied RGB;
это убирает лишь редкие отклонения alpha до 3/255 у старых квантованных тайлов.

См. `data/tile-merge-report.json` (исходные SHA-256, коэффициенты, ошибки),
`data/report-0.8.6.md` (проверки). Метрики новых 13 семейств в `matrices-report.json`
помечены `metric_reference`; старые записи декоративов/sand-1/heat-1 по-прежнему
относятся к upstream. Исторические `selection.md`/`compare-variants.md` не описывают 0.8.6.

Не затрагиваются объединением: снег и лёд (разные рисунки), grass-3/4 (один цвет),
декоративы, деревья и камни.

| `colors.py` | цвета карты и частиц против текстур, отчёт `data/colors-report.md` |

Запуск всегда `python -I -B путь/к/скрипту`,
пути к данным — аргументами.

## Где взять исходники upstream

Оригиналы (192 МБ графики) в мод не входят. Нужные версии скачиваются с портала
(требуется вход): `alien-biomes` (код) и `alien-biomes-graphics` (графика), см.
`data/upstream-*-manifest.json`. Распаковать каждый ZIP в свою пустую папку и передавать
путь аргументом. Совпадение с тем, на чём собран мод, проверяется по SHA-1 из манифестов
(`reforge.py graphics --upstream ...` покажет 0 изменений).

## Экономный атлас (настройка «Память под графику ландшафта»)

Startup-настройка `alien-biomes-reforged-atlas`: `normal` (по умолчанию) или `economy`.
Экономный режим не добавляет файлов — он только реже использует уже имеющиеся
(`prototypes/reforged/economy.lua`):

| Что | Как |
|---|---|
| Тайлы | те же матрицы и tint, что в normal; только варианты 1×1 и 8 из 16 вариантов 2×2; кадры 4×4 не грузятся |
| Декоративы | у декоративов этого мода с 6+ картинками остаётся каждая третья |
| Деревья | похожие виды берут графику соседа (willow→mangrove, greypine→conifer-01, specter и scarecrow→oaktapus, pear→ash), у каждого вида — первая половина вариаций, без карт нормалей |

Что сохраняется ради сохранений: имена прототипов, число вариаций каждого дерева
(лишние вариации получают графику оставшихся), тайлы и декоративы выбирают картинку по
позиции. Переключать можно на существующей карте — меняется только вид.

Историческая оценка 0.8.2 по загружаемым областям (`tools/atlas_regions.py`, без учёта
обрезки прозрачных краёв движком): оригинал 1374 МиБ, обычный 710 МиБ, экономный 188 МиБ.
После объединения 0.8.6 normal: **578.9 → 510.6 МиБ** (−68.25 МиБ RGBA8-эквивалента
относительно 0.8.5). Economy: **161.6 → 161.6 МиБ** — уже использовал по одной основе.
Это не реальные замеры VRAM. Актуальная проверка: `data/report-0.8.6.md`.
Отдельные `economy.py` и `economy-tints.json` удалены: альтернативных цветов больше нет.
Проверка экономного режима: `run_isolated.py dump RUN . --set alien-biomes-reforged-atlas=economy`.

## Цвета карты и частиц

`tools/colors.py` сравнивает цвет каждого тайла на карте (`map_color` автора) и цвет частиц
групп биомов со средним цветом того, что реально рисуется (PNG × `tint`). Светлота не
учитывается — автор делает карту светлее, чтобы она читалась; расхождением считается только
другой оттенок (хроматическое расстояние CIELAB > 10). Отчёт: `data/colors-report.md`.

Результат 0.8.3: исправлять нечего. Карта: медиана расхождения 1, частицы: 2–5. Выше порога
только вулканика, и это намеренно: раскалённая heat-4 ярко выделена на карте как самая
медленная местность, а частицы — серые обломки породы, а не свечение трещин.
Тайловые `particle_tints` движок использует только для брызг воды, на суше они не нужны.
Повторная проверка 0.8.6: `data/colors-report-0.8.6.md`, новых несоответствий нет.
Перепроверять после замены текстур: `colors.py report DUMP tools/data/colors-report-VERSION.md`
(исторические отчёты сохранять).

## Геология по цвету почвы (ПР-062)

Startup-настройка `alien-biomes-reforged-geology` (по умолчанию включена). Соответствие
«цвет почвы → ресурс» живёт в `scripts/geology-map.lua` и используется двумя путями:

- стадия данных: `prototypes/reforged/geology.lua` строит шумовые выражения
  `alien-biomes-geology-<ресурс>` — 2 там, где климат (temperature, moisture, aux) даёт
  подходящий цвет почвы, иначе 1. Цвет берётся из объёмов `biome-spec.lua` без
  потайлового шума плиток: граница следует климату. Трава считается там, где по влажности
  преобладает трава, иначе грунт и песок; вулканика — по температуре; снег и лёд ничего не
  выделяют. RSO Reforged 9.1.0 (`RSO-reforged/prototypes/noise.lua`) умножает на эти
  выражения веса ресурсов при выборе ресурса месторождения;
- стадия управления: `remote.call("alien-biomes-reforged", "geology_bias", surface_name,
  tile_names)` — таблица множителей для доминирующей почвы или `nil`, для генераторов на
  скриптах.

Без Reforged или с выключенной настройкой выражений нет, и RSO выбирает ресурсы без геологии.
Стартовая зона RSO не затрагивается. На карте с seed 20261022 доля подходящего ресурса на
своей почве выше средней в 1,4–2,0 раза.

Проверка логики без игры: `lua tools/test_geology.lua .`.

## Деревья: тени и карты нормалей в половинном разрешении

Тени деревьев — мягкие тёмные маски, карты нормалей только модулируют свет; в половинном
разрешении на экране они не отличаются, а в атласе занимают в 4 раза меньше. Стволы и листва
остаются в полном разрешении (это то, что видно).

- `tools/trees.py DUMP ПАПКА_graphics` берёт оригиналы upstream, кадр за кадром дополняет до
  чётного размера прозрачными пикселями справа/снизу, уменьшает вдвое (Lanczos по
  premultiplied RGBA) и складывает только используемые кадры. Список файлов и SHA-1
  исходников — `data/derived-graphics.json` (статус `derived` в манифесте графики).
- `prototypes/reforged/trees.lua` переписывает описания этих спрайтов: размер кадра
  `ceil(w/2) × ceil(h/2)`, `scale × 2`, `shift` прежний. Другая раскладка листа — ошибка при
  загрузке, чтобы смена формата upstream не прошла незаметно.
- После генерации — pingo, затем `pngverify.py МОД МАТРИЦЫ ПАПКА_graphics --derived-ref КОПИЯ_ВЫХОДА_trees.py`
  (сохраните выход генератора до pingo, чтобы сравнить с ним).

Исторические результаты 0.8.5 (по загружаемым областям): деревья 382 → 250 МиБ, весь мод в обычном режиме
710 → 579 МиБ, в экономном 188 → 162 МиБ. Графический запуск base + Quality + Elevated Rails +
Reforged: все спрайты загружены, видеопамять 2023 МБ (атласы 2012 МБ, DXT).

## Процедуры

### Вышла новая версия кода Alien Biomes

```
python -I -B tools/reforge.py code --upstream ПАПКА_alien-biomes --dry-run   # что изменится
python -I -B tools/reforge.py code --upstream ПАПКА_alien-biomes
python -I -B tools/reforge.py check
```

`code` заменяет файлы upstream (Lua — всегда, с переписыванием путей
`__alien-biomes__`/`__alien-biomes-graphics__` → `__Paranoidal-Alien-biomes__`; остальные —
только если upstream их изменил, чтобы не затереть результат pingo), удаляет то, что
upstream удалил, заново применяет `patches.py`, переносит записи changelog Reforged
поверх нового changelog upstream и обновляет манифест. Графику, `tools/`, `info.json`
и собственные файлы Reforged не трогает.

Если якорь правки не найден, команда сообщает `PROBLEM` и код возврата 1: открыть новый
код upstream, понять, что поменялось, исправить запись в `patches.py` и повторить.

Дальше: поднять версию в `info.json`, запись в `changelog.txt`, dump
(`run_isolated.py dump`) и `dumpdiff.py` против dump'а оригинальной пары той же версии.

### Вышла новая версия графики

```
python -I -B tools/reforge.py graphics --upstream ПАПКА_alien-biomes-graphics          # отчёт
python -I -B tools/reforge.py graphics --upstream ПАПКА_alien-biomes-graphics --apply  # скопировать kept
```

- `kept` изменились — копируются как есть, потом pingo.
- `matrix` изменились — пересобрать матрицы этих семейств (следующий раздел).
- `derived` изменились — пересчитать инструментом, указанным в `data/derived-graphics.json`.
- В конце `reforge.py manifest --code ... --graphics ...` с новыми релизами.

### Пересобрать матрицы

Воспроизвести объединение 0.8.6 можно из **резервной копии до объединения**:

```
python -I -B tools/merge_tiles.py --source BACKUP/Alien-biomes-Reforged --out WORK/merged
python -I -B tools/reforge.py matrices --selection WORK/merged
python -I -B tools/test_merge_tiles.py
```

`WORK/merged` должен отсутствовать. Генератор не меняет источник, сохраняет все
неизменяемые матрицы и полный `report.json`; `matrices` проверяет полный набор семейств,
копирует PNG без обработки, регенерирует Lua и удаляет только устаревшие управляемые
матрицы из прежнего отчёта. Не запускайте установку поверх уже сжатых новых PNG без нужды.
Превью всех 128 затронутых цветов — `WORK/merged/previews/`.

Для обновления из новой графики upstream (другой эталон):

```
python -I -B tools/abtint.py survey ПАПКА_graphics/graphics WORK/survey
python -I -B tools/abtint.py build ПАПКА_graphics/graphics WORK/rgb tools/data/plans/plan-rgb-minimax.json
...  (другие одногрупповые планы, additive для лавы)
python -I -B tools/select.py WORK/final 36 0.95 minimax=WORK/rgb ...
python -I -B tools/reforge.py matrices --selection WORK/final
```

Выборка должна содержать все текущие семейства; `select.py` не допускает возврата
к g1/g2 для тайлов. Старые планы k2 служат только для сравнения. После ручного сжатия
используйте `pngverify.py` с сохранёнными несжатыми PNG; отдельный economy-пересчёт не нужен.

### Проверки перед коммитом

1. `reforge.py check --png` — пути, правки, PNG.
2. `FACTORIO_EXE` задаёт путь к текущему движку; `run_isolated.py dump RUN .` и второй
   запуск с `--set alien-biomes-reforged-atlas=economy`. Сравнение с копиями до изменения:
   `test_merge_tiles.py --dumps OLD_NORMAL OLD_ECONOMY NEW_NORMAL NEW_ECONOMY`.
   Аргументы — пути к четырём `data-raw-dump.json`. Проверяются не только наборы прототипов,
   но и отсутствие изменений за пределами picture/tint тайлов.
3. Dump всей сборки через `test-runs/_tools/factorio_check.py` (правила запуска — в
   `agent-context/procedures/TESTING.md` рабочей копии проекта).
4. Вид в игре — приёмка пользователем.
