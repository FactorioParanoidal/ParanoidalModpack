# Изменения Paranoidal в Even Distribution 2.0.2

Локальный portal-патч (`mods-metadata/even-distribution.json`). Цель — убрать лишнюю нагрузку на
процессор и ошибки, сохранив функции мода: CTRL+перетаскивание (распределение/выравнивание),
SHIFT+C (уборка инвентаря), настройки, remote-интерфейс. Основа — upstream 2.0.2; с 2026-10-21
версия форка 9.0.2 (9.x — локальный форк). При обновлении с портала эти правки нужно перенести или
проверить заново.

## Мусор по умолчанию для SHIFT+C (9.0.2)

Список `default-trash.lua` задан по группам/подгруппам предметов. В 2.0 группы Angels получили
приставку `angels-` (`resource-refining` → `angels-resource-refining`, `petrochem-refining`,
`water-treatment`, `bio-processing-nauvis/-vegetables/-alien` — так же), а `coal-crushed`,
`wood-pellets`, `wood-bricks` стали `angels-*`. Старые имена не находились, и руда, дроблёная руда,
шлак, камень, уголь, кокс, био- и водоочистные предметы перестали быть мусором по умолчанию
(916 предметов в Beta 8 → 681 в 2.0). Добавлены новые имена, старые оставлены; теперь 974 предмета
по эталонному дампу 2.0.77. Топливо по-прежнему оставляет 2 стопки, если не указано по имени.
Смена версии нужна, чтобы `on_configuration_changed` пересобрал `storage.defaultTrash` в старых
сохранениях.

## Исправленные ошибки
- `scripts/metatables.lua`: поиск в кэше по `LuaEntity` (в 2.0 это userdata) всегда давал `nil` — удаление разрушенных/разобранных сущностей из кэша перетаскивания не работало.
- Сортировка топлива использовала некорректный компаратор (цепочка `or`), порядок «хуже → лучше» был случайным.
- Урон боеприпасов считался как 0 почти для всех (цепочка `or` останавливалась на первом слагаемом) — замена «худших» боеприпасов шла в случайном порядке. Расчёт исправлен (`scripts/protocache.lua`).
- `scripts/util.lua`: обход кэша при переходе на другую поверхность продолжал с координаты прошлой поверхности и падал на пустых вложенных таблицах.
- `on_init` зависел от порядка обработчиков скриптов (`storage.guiEvents` мог быть ещё не создан) — реестр создаётся при первом обращении.
- Устаревшие (прошедшие) записи `storage.distrEvents` держали `on_tick` включённым навсегда — теперь очищаются.
- `to_be_deconstructed()` вызывается без аргумента (API 2.0); `previous_recipe` печи читается как пара `{name, quality}` 2.0.
- Удалён неиспользуемый код на API 1.1 (`game.recipe_prototypes` в `util.enablesRobots`), исправлена опечатка `effects.action` в расчёте радиуса.
