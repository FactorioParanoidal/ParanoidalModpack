# MxlChievements (Reforged)

Мод достижений сборки Paranoidal. Объединяет два мода и исправляет их ошибки:

- **MxlChievements** 3.0.1 (Mxlppxl, через форк сборки MxlChievements2) — достижения за выпуск
  сотни с лишним предметов, за выпуск в час и за длину маршрута поезда;
- **More Achievements** 0.0.2 (LuziferSenpai) — новые ступени производственных достижений базовой
  игры и их варианты по качеству.

Мод работает только на этапе данных: у него нет `control.lua`, хранилища, сущностей и предметов.
Имена прототипов достижений сохранены, поэтому полученные достижения и прогресс переносятся
везде, где имя не менялось (см. «Переход со старых модов»).

## Что добавляет

В текущей сборке (Factorio 2.0.77, Quality и Elevated Rails, без Space Age) загружается
**534 достижения**, из них 519 новых и 15 изменённых базовых.

## Особенности

- **Только существующее.** Достижение создаётся, если его предмет, жидкость и качество есть в
  итоговых данных и не скрыты. Проверка идёт в `data-final-fixes` после zzzparanoidal и
  ic-more-qualities, поэтому видит и предметы, добавленные поздно (турбо-ленты Bob,
  литиевая пластина и т. п.).
- **Описания генерируются из условия.** Текст собирается из реального порога, иконки и названия
  предмета, а также качества, например «Произведите [иконка] Процессор (Редкое): 25 тыс. за час.».
  Число в описании не может разойтись с условием, названия предметов берутся из локали сборки.
  Числа: тыс. / млн / млрд / трлн (в EN — k / M / G / T).
- **Качество — настоящий фильтр** `item_product = {name, quality}` из API 2.0.
  Значок и название качества берутся из активных прототипов качества, поэтому подходят и к
  ic-more-qualities.
- **Иконки.**
  - У серий с собственной картинкой (бронзовая шестерня-рамка с предметом) одна картинка на ступень
    или общая для серии.
  - Для предметов без своей картинки иконка предмета вставляется в рамку: бронза, серебро,
    золото по ступени.
  - У новых ступеней базовых достижений есть отметки II и III, у качественных вариантов —
    маленький значок качества.
- **Сортировка.** Базовые серии стоят на своих местах в окне достижений, в порядке ступень →
  качество. Каталог идёт после них, в порядке файла.
- **Одна лестница на продукт.** Серии MxlChievements, которые повторяли базовые лестницы
  (электросхемы, железо в час, улучшенные схемы в час, процессоры в час), удалены. Совпадающих
  по смыслу достижений (тип, продукт, качество, порог) в сборке нет.
- **Защиты.**
  - Повтор имени внутри мода — ошибка загрузки, чтобы опечатка не потерялась молча.
  - Имя, уже занятое другим модом, пропускается с записью в лог.
  - Новая ступень не выше предыдущей — предупреждение в лог.
  - Если базовую лестницу изменил другой мод (нет нужной ступени), серия не трогается.
- **Прогресс между сейвами.** У `produce-achievement` стоит `limited_to_one_game = false`, как в
  исходных модах.

## Совместимость

- Зависимости: `base >= 2.0`, необязательные `quality`, `space-age`, `zzzparanoidal`,
  `ic-more-qualities` (нужны для порядка загрузки).
- Несовместим с `MxlChievements`, `MxlChievements2` и `more-achievements`: этот мод их заменяет.
- Без Quality: качественные варианты и `gear-production-1a…1d` не создаются, остальные
  достижения засчитывают предмет любого качества.
- Без zzzparanoidal и Bob мод тоже работает: пороги базовых ступеней будут ванильными.

## Устройство

```
data-final-fixes.lua        точка входа: builder.build(base-series, catalog)
prototypes/base-series.lua  лестницы базовых достижений: продукт, новые пороги, картинка, порядок
prototypes/catalog.lua      каталог MxlChievements: одна строка — одна серия
prototypes/builder.lua      проверки, иконки, качество, описания, порядок, защита от дублей
locale/{en,ru}/locale.cfg   названия достижений и шаблоны описаний
graphics/                   картинки серий, рамки base/base-silver/base-gold, отметки tier-2/3
```

## Как добавить достижение

Строка каталога: `{префикс, предмет, картинка, параметры…}`.

```lua
{"iron-stick", "iron-stick", "iron-bar-1"},                    -- iron-stick-1..3: 1 млн / 1 млрд / 1 трлн
{"lamp", "small-lamp"},                                        -- без картинки: иконка лампы в рамке
{"coal-madness", "coal", "iron-bar-1", per_hour = true, amounts = {1e6, 5e6}},
{"red-gears", "iron-gear-wheel", "gear-production-1", single = true, amounts = {1e7}, quality = "rare"},
```

| Поле | Значение |
|---|---|
| `[1]` | Префикс имени: `<префикс>-1`, `<префикс>-2`, … (с `single = true` — просто `<префикс>`) |
| `[2]` | Предмет; по умолчанию равен префиксу |
| `[3]` | Картинка из `graphics/` без `.png`; `%d` заменяется номером ступени. Без картинки — рамка с иконкой предмета |
| `amounts` | Пороги по ступеням, по умолчанию 1e6 / 1e9 / 1e12 |
| `per_hour` | Выпуск в час (`produce-per-hour-achievement`) |
| `fluid` | Жидкость вместо предмета |
| `quality` | Засчитывается только это качество. `"normal"` без Quality снимается, другие качества без Quality пропускаются |
| `train` | Длины маршрута поезда — серия `train-path-achievement` |
| `product_icon` | `{file, size}` — своя картинка внутри рамки вместо иконки предмета |

Затем добавьте названия в `locale/en/locale.cfg` и `locale/ru/locale.cfg` в секцию
`[achievement-name]`. Описания писать не нужно.

Новая ступень базовой лестницы — число в `extra` нужной записи `base-series.lua`. Новая лестница
базовой игры — новая запись с полями `name`, `type`, `item`, `base_tiers`, `extra`, `icon`, `order`
и названием серии в `[mxlr-series]`.

Перед добавлением серии проверьте, что тот же продукт с похожими порогами ещё не покрыт другой
лестницей.

## Ограничения

- В ic-more-qualities `legendary` — пятый уровень из примерно сорока, поэтому качественные
  варианты сравнительно доступны.
- Локализация: английский и русский; в остальных языках будут английские тексты.
- Названия для серий Space Age есть только на английском: в сборке они не загружаются.
