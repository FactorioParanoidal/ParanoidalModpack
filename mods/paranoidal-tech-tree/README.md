# Paranoidal Tech Tree 0.2.0

Окно исследований на обычном GUI Factorio 2.0: ни `camera`, ни `rendering`, ни создания игровых поверхностей.

## Управление

Одна строка сверху: «Всё дерево / Цепочка», «Закрепить», поиск, цель, меню «Вид», закрыть. Под ней — очередь.

- **Ctrl+T** — открыть/закрыть. **Esc** или ✕ — закрыть окно.
- **Всё дерево / Цепочка.** «Цепочка» — выбранная технология, все её предки и следующие исследования. Пока игрок сам ничего не выбрал, показывается всё дерево; первый клик по технологии включает «Цепочку».
- **Закрепить** — сохраняет цепочку: клики по другим карточкам меняют только правую панель, дерево не прыгает.
- **Поиск** — по внутреннему имени и переведённому названию; × очищает.
- **Вид** — размер карточек (48, 64, 80, 96 px) и «К выбранной».
- **Только вертикальная прокрутка.** В каждой эпохе одна сетка карточек, упорядоченная по этапам зависимостей; номер этапа — в подсказке карточки.
- **Эпохи научных пакетов.** Технология относится к эпохе своего самого старшего научного пакета (предметы группы `science-pack`). Порядок пакетов вычисляется по самому раннему этапу, где пакет используется, без ручного списка. Технологии без научных пакетов, но с другими предметами в стоимости (детали модулей, данные спутников) образуют эпоху этого предмета. Технологии, открываемые действием (скрафтить, добыть, построить), стоят в эпохе своих предков; точное условие — на карточке и в правой панели.
- **Сворачивание.** В полном дереве открыты только эпохи, где сейчас есть что изучать; −/+ у заголовка сворачивает эпоху. Изученные карточки скрыты за кнопкой «Показать изученные (N)».
- **Навигатор слева** — эпохи со счётчиком «изучено/всего»; стрелкой отмечена эпоха выбранной технологии.
- **Подсказка слева внизу** — строка «что делать сейчас» (выбрать технологию → сделать целью → цель задана / на паузе) и сворачиваемая памятка «Как пользоваться»; свёрнутость запоминается для каждого игрока.
- **Карточка**: цвет иконки — статус (зелёный — изучено, жёлтый — можно ставить сейчас, синий — в очереди, красный — отключено); метка «осталось N» — сколько неизученных технологий нужно, включая эту; оранжевая — если технология на пути к выбранной.
- **Очередь** — 7 слотов (лимит движка 2.0.77): клик — выбрать, Shift+клик — поднять выше (если не зависит от предыдущей), правый клик или × — убрать. Жёлтая рамка — поставлено целью.

## Путь и цель

В правой панели у неизученной технологии — «Путь к этой технологии»: сколько осталось, сумма научных пакетов, «Можно ставить сейчас», ожидающие игрового действия, отключённые, затем волны 2–5.

**Сделать целью** — одна общая цель на force, с подписью «задал». Мод ставит технологии пути только в свободные места в конце обычной очереди через `force.add_research`: сначала ранние волны, внутри волны — то, что открывает больше шагов пути. Ручные пункты очереди не трогаются и не переставляются. После каждого изученного исследования свободные места дозаполняются. Если игрок убрал из очереди нужную цели технологию, цель встаёт на паузу до «Продолжить». По достижении цель снимается с сообщением в чат. Исследования и пакеты не выдаются.

## Установка и ограничения

Папка `mods/paranoidal-tech-tree`. Окно открывается по **Ctrl+T**; настройка замены стандартного окна выключена по умолчанию. При обновлении мода состояние окон сбрасывается, цель сохраняется; исчезнувшая технология-цель снимается с сообщением.

Ctrl+T зарезервирован для дерева: стандартное назначение снято с переключателя панели исследований (More Minimap Autohide), Rich Text (Helmod) и менеджера Cybersyn. Личные переназначения не перезаписываются.

Проверено на Factorio 2.0.77 с полным модсетом Paranoidal (1266 видимых технологий, 1920×1080, масштаб 1): обработчики с реальными элементами GUI, цель, автодозаполнение, пауза/продолжение, перестановка и удаление в очереди, достижение цели, сохранение/загрузка. Не заявлены: физические клики ОС, MP, другие разрешения и DPI.
