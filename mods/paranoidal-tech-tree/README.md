# Paranoidal Tech Tree 0.1.0

Полная замена экспериментальной версии 0.0.x. Только обычный GUI Factorio 2.0: ни `camera`, ни `rendering`, ни создания игровых поверхностей.

## Управление

- **Ctrl+T** — открыть/закрыть. **Esc** и «Закрыть» — закрыть окно.
- **− / +** — четыре размера иконок: 48, 64, 80, 96 логических пикселей. При смене размера карточки и отступы пересчитывает сам GUI. Масштаб не опускается ниже читаемого размера.
- **Колесо мыши и полосы прокрутки** — перемещение. Мод не перехватывает колесо/стрелки.
- **К выбранной** — вернуть выбранную карточку в видимую область, сбросив поиск.
- **Цепочка выбранной** — выбранная технология, все её предки и непосредственные следующие технологии. Снимите галочку для просмотра всех технологий.
- **Поиск** — по внутреннему имени и переведённому названию. Переводы запрашиваются постепенно при первом открытии; русский поиск может потребовать несколько секунд.
- **Нажатие на иконку** — выбор технологии. Справа — необходимые предки, следующие технологии и рецепты; иконки технологий там также кликабельны.
- **Начать / добавить в очередь** — вызов обычного `force.add_research`. Недоступные исследования не запускаются. Научные пакеты и исследования не выдаются, существующая очередь не переупорядочивается.

Это **слои зависимостей с карточками**, не свободно перетаскиваемое полотно и не уменьшенная копия стандартного дерева с тысячами линий. Конкретные связи показывает правая панель. Кнопки «уместить 1200 иконок на одном экране» нет намеренно.

## Установка и ограничения

Мод поставляется отдельной папкой `mods/paranoidal-tech-tree`. Включите «Дерево исследований Paranoidal» в списке модов и перезапустите игру. Окно открывается по **Ctrl+T**; настройка замены стандартного окна выключена по умолчанию. В существующем сейве после обновления 0.0.x старые окна закрываются; старая служебная поверхность не удаляется во избежание потери неизвестного содержимого. Новая версия её не использует.

Проверено на Factorio 2.0.77 с Paranoidal: 1218 видимых технологий, min/max размер и ограничения, полный список, русский поиск, вызовы обработчиков кнопок с реальными GUI-элементами, add_research и отказ закрытого исследования, закрытие/повторное открытие, загрузка сохранённого окна. Снимки — 1920×1080, масштаб интерфейса 1.

Не заявлены: физические OS-клики/колесо, MP, произвольный DPI/размер окна, полная прогрессия и достижимость исследований. Обычные структуры состояния отдельные для каждого игрока/force, но MP отдельно не испытан. Родное окно остаётся доступным.
