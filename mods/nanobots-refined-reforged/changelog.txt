Version: 9.0.7
Date: 2026-10-21
  Changes:
    - Renamed to nanobots-refined-reforged, the Paranoidal fork of nanobots-refined (title "Nanobots: Early Bots Refined (Reforged)"); version 9 against portal auto-updates. Prototype, setting and key names are unchanged. An existing save keeps the entities and items but starts with fresh mod storage (custom ranges, queues).
  Features:
    - Firing speeds (for both manual and auto modes) are now configurable.
  Changes:
    - Updated mod description.
  Bugfixes:
    - Auto mode no longer spams "attempt to index local 'character' (a nil value)" (nanobots-auto.lua:194) every tick after the player dies; players without a character are skipped until respawn.
    - Removed extraneous zipped version of Russian localization.
    - Fixed bug preventing Bob's mods recipe replacements from working.
    - Fixed error "attempt to call global 'set_stack'" when fillers handle an insert request in cheat mode; a missing request count no longer errors either (Paranoidal local fix).
  Graphics:
    - Roboport interface uses its HR sprites directly (2.0 ignores hr_version) (Paranoidal local fix)
  Optimizations:
    - Auto mode asks the engine for the targets instead of fetching every entity in reach (trees, ore, belts) each second: marked for deconstruction, the force's upgrades, ghosts and item requests, then its damaged entities. Every target is still classified as before; only the queueing order follows these groups (Paranoidal local fix)
    - The queue limit of 100 tasks works again: Queue.count read undefined globals and always reported 0, so the queue grew without bound and every refill re-checked all queued targets. Refills skip already queued targets first and don't scan at all while the queue is full (Paranoidal local fix)
    - The player checks (character, emitter and ammo, construction network, radius) are made once per player and tick instead of for every task and target; the per-target network check repeated the same search at the character's position (Paranoidal local fix)
    - Bounded work per tick: at most 10 failing tasks are skipped per tick, at most 250 search results are classified per refill (the next refill goes on from there), a queue that drains on failures waits one launcher cooldown before the next scan instead of rescanning every tick, and a queue that cannot run at all (no ammo, inside a construction network) is dropped at once (Paranoidal local fix)
    - Supply checks are shared by ghosts of the same item within a refill; health is checked first for repairs; game.connected_players is read once per tick; armor chips skip grids without chips with one call (Paranoidal local fix)
    - The roboport interface queue keeps a count instead of walking the whole queue for every cell and signal (Paranoidal local fix)
  Bugfixes:
    - Nanobots work in remote view: targets were searched on the camera's surface and measured from the camera's position. Combat robots, item and tree marking of the armor chips, building and tile deconstruction also use the character's or the target's surface (Paranoidal local fix)
    - The feeder chip heals without an error: 2.0 has no 'flying-text' entity, it shows local flying text now (Paranoidal local fix)
    - A re-queued emptying/filling task keeps its queue hash (it was cleared right after re-queueing) (Paranoidal local fix)
    - Clearing items under a ghost is validated again (the check was spelled 'clear-ground' and never ran), so all-pending items no longer print "No clearable stacks found" (Paranoidal local fix)
    - Levelers search trees and cliffs only within their 120-target limit, so an ore patch in reach no longer hides the trees (Paranoidal local fix)
    - The roboport interface wood and fish limits work: get_contents() is an array in 2.0, and the items are now wood and raw-fish (Paranoidal local fix)

Version: 4.0.0
Date: 2025-07-08
  Features:
    - Added Manual Mode, where nanobots only trigger when you fire the emitter. (On by default.)
    - Replaced projectile graphics.
    - Added projectile impact sounds.
    - Added "Out of supplies" and "All complete" sound effects.
    - Termites are now Levelers, and destroy all natural features. (Option to limit cliffs.)
    - Added option to let Levelers destroy trees and rocks marked for deconstruction. (On by default.)
    - Levelers can optionally also place landfill.
  Changes:
    - Overhauled nanobots' inner workings. This could result in new bugs.
    - Moved speed and range upgrades to have a smoother curve.
    - Nanobots have a more fitting, but more expensive recipe. (Option to revert.)
    - Nanobots can now use cliff explosives (but not other explosives) without "Nano Explosives" technology.
    - "Nano Explosives" technology is now hidden by default.
    - "Nano Explosives" technology now requires "Military 2". (This was already required for it to have any effect.)
    - Constructors now must empty inventories before mining entities.
    - Constructors now must clear dropped items before building entities.
    - Constructors are now limited to moving 10 items or one stack at a time.
    - Constructors can no longer build using items currently held in cursor.
    - Removed several technical or auto-mode-balancing settings.
    - [Auto Mode] Incorporated repairs into queue.
    - [Auto Mode] Removed AFK detection.
    - [Auto Mode] Slowed queue processing speed significantly, to encourage use of Manual Mode.
    - [Auto Mode] Removed queue speed setting.
    - [Auto Mode] Removed pauses when queue empties.
    - [Auto Mode] Removed option to use Nano Emitter without equipping it.
    - [Auto Mode] Levelers now also use the queue.
  Bugfixes:
    - Constructors can now build tiles (e.g. landfill) below entity ghosts.
    - Constructors no longer ignore quality. (Note: not tested.)
    - Constructors no longer throw errors when attempting to fulfill item requests.
    - Constructors no longer mine foundation tiles (e.g. landfill) when placing non-foundation tiles (e.g. concrete) over them.
  Info:
    - First version by foxoftheasterisk
