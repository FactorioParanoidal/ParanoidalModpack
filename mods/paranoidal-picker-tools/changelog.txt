Version: 9.0.0
  Locale:
    - Russian hardcoded player-facing text: 6 UI, chat, command-help and error-message literals; technical identifiers, format parameters and gameplay logic are unchanged.
Date: 2026-11-01
  Bugfixes:
    - Quality scrolling follows the quality chain instead of prototype levels, so all five defect tiers are distinct from normal. Both directions wrap safely and stop after one complete pass, including when no matching item is available.
    - Quality scrolling safely ignores an empty cursor or missing main inventory, swaps real stacks without rebuilding them, and rebuilds its derived order lazily after loading instead of relying on old saved ordering.
  Major Features:
    - Paranoidal: new mod paranoidal-picker-tools. Merges kry-picker-extended 1.1.0, yemtositemcount 0.7.2, belt-reverser-space-age 2.0.1, beltbrush2-reforged 0.2.1 and even-pickier-dollies 2.7.5 into one mod. Custom input, setting, shortcut, item, locale and mod-data names are unchanged, so keybindings and per-player settings stay. The remote interface PickerDollies and its dolly_moved_entity_id event are kept for the mods that use them; the picker interface (set_blacklisted_chests, get_blacklisted_chests) is now named paranoidal-picker-tools.
  Changes:
    - Belt brush default keys: type cycling ALT + C / ALT + SHIFT + C (was CONTROL + R, shared with Factory Planner, Bob's Inserters, Factorissimo and RuNames), balancer cycling ALT + B / ALT + SHIFT + B (was CONTROL + B, shared with the planner menu). Rebound keys are kept.
    - Handlers are no longer wrapped in pcall: an error stops the game with its traceback instead of being printed to chat with the action left half done.
    - Belt reverser: only belts of the player's force are reversed; the rotations raise on_player_rotated_entity.
    - Dollies: the default blacklist and oblong lists are merged into storage on init instead of replacing names other mods added before.
    - Removed: Polish dollies locale, locale keys of features the mod no longer has (old belt brush and reverser copies, item count setting, screenshot camera, ore eraser, paste modifier, multiple craft), the 2.6.1 dollies migration, LuaLS type files.
  Optimizations:
    - One engine registration per event for the whole mod: on_player_cursor_stack_changed (chest limit, item count, dollies), on_selected_entity_changed (searchlight, ghost revival, dollies) and on_built_entity each run one handler list.
    - Belt reverser: one entity search per tile instead of three, and the segment walks are loops instead of recursion (long belts no longer build a deep Lua stack).
    - Item count: setting lookups and the ignored item set are no longer rebuilt on each inventory change; no global functions.
  Info:
    - Saves: storage of the old mods is not carried over. Lost: per-player picker data, planner menu order, quality scroll state, the dollies saved entity and names other mods added to the dollies lists (the mods of the modpack that add names do it again on load or on a configuration change). Entities, settings and keybindings are kept.
  Compatibility:
    - Paranoidal port to Factorio 2.1: factorio_version set to 2.1.
    - Factorio 2.1 runtime API: dollies move by build_grid_size (building_grid_bit_shift was removed; its 2.0 values equal the 2.1 grid sizes) and the belt reverser follows underground belts through underground_belt_neighbour (LuaEntity::neighbours was removed).
    - Factorio 2.1: the adjustment pad hotkeys use the documented key names KP_PLUS and KP_MINUS (2.1 removed the undocumented names PAD + and PAD -; the hotkeys had no default key).

Version: 1.1.0
Date: May 26, 2026
  Changes:
    - Paranoidal: no longer needs kry_stdlib. Event handling, player data, colors and the prototype helpers are part of the mod; storage keeps the same layout and the color setting values are unchanged.
    - Paranoidal: removed the built-in Item Count, Belt Reverser and Belt Brush copies (they switched themselves off next to yemtositemcount, belt-reverser-space-age and beltbrush2-reforged, which the modpack ships) and the unused old reviver and picker scripts.
    - Paranoidal: the remote interface keeps set_blacklisted_chests and get_blacklisted_chests only (the stdlib write_global and dump_all used the 1.1 API).
  Optimizations:
    - Paranoidal: events reach the handlers directly instead of through the kry_stdlib dispatcher; a handler error is still caught, logged and printed. Ghost revival on hover reads its four player settings only when a revival is possible.
  Graphics:
    - Paranoidal: removed 20 images no prototype used (left over from Picker Extended tools this mod does not have); the remaining PNG files and the thumbnail recompressed with pingo, pixel-identical (60 KB -> 8 KB).
  Major Features:
    - Auto Ghost Revival: Improved compatibility with entities that have a different placeable_by item
      This allows compatibility with mods such as Flow Configuration and Mini/Micro Machines
  Minor Features:
    - Extended entity family functionality from just rail variants to the following:
      rails/signals, belts/splitters/underground, pipes/underground, and all inserters.
      This allows holding any member of the family in the cursor to revive any other member, if the matching item(s) are in theh player inventory, and should respect quality.
  Bugfixes:
    - Paranoidal: automatic circuit wires work again (2.0 wire API; the 1.1 check matched no pole and the 1.1 calls do not exist in 2.0). With the shortcut on, every pole a player builds gets a red/green wire to a copper-connected pole when, for that colour, those poles carry exactly one network and the new pole has none; two networks are never joined; hidden poles of other buildings are ignored. The robot setting is renamed to picker-auto-circuit-robots and is off by default (the old picker-auto-circuit-bots was on).
    - Paranoidal: chest contents mover (Shift+C / Shift+V) works only when both chests are within the character's reach (not from remote view or across the map), except in cheat mode.
    - Paranoidal: ghost revival with "ignore quality" spends only items of the ghost's quality or better (defects count below normal); a worse item no longer builds a better entity.
    - Paranoidal: the "-N <module>" flying text when ghosts get modules from the inventory uses the item prototype's localised name, so items with an overridden name no longer show "Unknown key".
