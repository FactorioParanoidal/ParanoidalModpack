# Bob's Adjustable Inserters (локальный форк Paranoidal)

Исходный мод — Bob's Adjustable Inserters (автор Bobingabout). Изменения сборки описаны в `changelog.txt` (строки «Paranoidal», версия 2.0.3): сетка позиций для больших манипуляторов, ограничение позиций из чертежей изученными технологиями, фоновая проверка.

Оптимизации, версия 2.0.3:

- `on_built_entity` получает только манипуляторы и их призраки.
- После установки чертежа зона проверки считается один раз на чертёж в руке (хранится для игрока в `storage.bob_enforce.reach`, сбрасывается при смене курсора), а не копированием всего чертежа на каждую установку при протягивании.
- Проверка позиций кэширует пригодность прототипа по имени и читает технологии силы одним запросом.
- Собственные окна и код постройки вызывают функции мода напрямую, без `remote.call` в этот же мод. Интерфейс `bobinserters` для других модов не изменён.
- Сохранения совместимы, миграция не нужна.
