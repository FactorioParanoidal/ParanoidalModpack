# Advanced PARANOIDAL Settings

## Русский

Каркас собственного мода сборки для Factorio 2.0.77+. Сохранены имя
`zzzparanoidal-settings` и автор SEO-master из пользовательской Beta 8.

Версия 0.2.0 намеренно ничего не делает: не скрывает настройки, не задаёт
дефолты, не фиксирует значения и не изменяет сохранения. Включение или
отключение этой версии не должно менять баланс или видимость настроек.

Список скрытия будет адаптирован отдельно после переноса баланса настроек
Beta 8. Дефолты остаются в `zzzparanoidal`; этот мод предназначен только
для видимости. Опциональная зависимость задаёт порядок после
`zzzparanoidal`, если он установлен. Порядок относительно остальных модов
будет уточняться вместе с будущими правилами скрытия.

## English

Project-owned scaffold for Factorio 2.0.77+. Retains the internal name
`zzzparanoidal-settings` and author SEO-master from the user's Beta 8.

Version 0.2.0 is intentionally inactive: it does not hide settings, set
defaults, force values or modify saves. Enabling or disabling it should
not change balance or settings visibility.

Visibility rules will be adapted separately after the Beta 8 settings
balance is ported. Defaults belong to `zzzparanoidal`. The optional
dependency orders this mod after `zzzparanoidal` when present; other
ordering requirements will be evaluated alongside future hiding rules.
