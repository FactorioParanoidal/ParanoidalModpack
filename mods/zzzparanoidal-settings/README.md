# PARANOIDAL: hide balance settings

## Русский

Собственный мод сборки для Factorio 2.0.77+. Прячет стартовые настройки других модов
(вкладка «Запуск») из группы «баланс» по согласованной раскладке issue #125.
Значения в `mod-settings.dat` не меняются: спрятанная настройка продолжает действовать
с тем значением, которое было сохранено. Чтобы увидеть настройки, выключите мод.

Настройки, от которых зависит работа сборки (HeroTurretRedux), скрывает сам `zzzparanoidal`.

## English

Project-owned mod for Factorio 2.0.77+. Hides other mods' startup settings of the
"balance" group from the agreed issue #125 layout. Saved `mod-settings.dat` values are not
changed. Disable the mod to see the settings.
