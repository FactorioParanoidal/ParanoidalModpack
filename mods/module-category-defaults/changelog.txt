Version: 2.2.0
Date: 03.08.2026
  Features:
    - Added setting (default disabled) to attempt to auto-detect modded module categories that should be treated like vanilla categories.
  Changes:
    - Paranoidal (Space Age branch, a library of Moshine): a machine without its own module category list gets every module category of the build except the restricted ones, not only the vanilla categories (the build has Bob's and Beta 8 modules of its own: god, green, raw, pollution). Restricted: restricted_categories and the module categories of the planet mods (paranoidal-space-age-filter: the AI cores of Moshine go only into its computers) that no mod put into default_categories. With nothing restricted nothing changes: no list means all categories.
    - Paranoidal: loads after zzzparanoidal, ic-more-qualities and zzzparanoidal-start-bnl, so their data-final-fixes see the machines as without this mod and machines they create get the list too; agricultural towers are always processed (no Space Age check, data.raw has none without it); the autodetection setting is hidden and not used. Moshine declares its AI core category in its own data-final-fixes and calls process_entity_prototypes() then; here the library does nothing until a restricted category exists.
  Compatibility:
    - Added 'ModuleCategoryDefaults.restricted_categories' table for module categories that should be disabled for all entities.
    - Added 'ModuleCategoryDefaults.process_entity_prototypes()' function that can be called manually to pick up any entity prototypes created after this mod's 'data-final-fixes'.
    - Added 'ModuleCategoryDefaults.process_recipe_prototypes()' function that does equivalent logic for recipe prototypes (recipes are not processed by default).
