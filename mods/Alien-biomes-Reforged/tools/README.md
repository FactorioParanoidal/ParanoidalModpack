# Alien-biomes-Reforged — инструменты сопровождения

Эта папка — всё, что нужно, чтобы понять, проверить, пересобрать и обновить мод.
Игра её не читает; в ZIP мода она добавляет меньше 1 МБ.

## Зачем существует мод

Alien Biomes (Earendel, CC0) хранил каждый цветовой вариант почвы, песка, травы,
вулканической земли, дюн и лавы отдельной текстурой. Рисунок у вариантов один и тот же,
отличается только окраска, но каждая текстура занимает место в атласе спрайтов —
в сумме больше 2 ГиБ несжатого RGBA только у этого мода.

Reforged объединяет Alien Biomes 0.7.4 и Alien Biomes Graphics 0.7.1 в один мод и
рисует цветовые варианты из общих **тинт-матриц**: одна светлая текстура на семейство
плюс цвет `tint` в прототипе. Движок умножает текстуру на `tint` при отрисовке,
поэтому атлас хранит одну картинку вместо двенадцати.

Принципы, которые нужно сохранять при любых изменениях:

- **Имена прототипов и настроек upstream не меняются** (тайлы, декоративы, деревья,
  `alien-biomes-*`): сохранения и интеграции других модов продолжают работать.
- **Код upstream правится минимально.** Своя логика — в собственных файлах
  (`prototypes/reforged/`, файлы, которых нет у upstream); в код upstream она
  подключается короткими правками из `patches.py`. Тогда новую версию Alien Biomes
  можно накатить командой `reforge.py code`, а не вручную.
- **Готовые PNG не перегенерируются без нужды.** После генерации PNG оптимизируются
  pingo (css-ig.net); инструменты не затирают уже оптимизированные файлы.
- **Каждый шаг проверяется**: цифрами (PSNR/SSIM), превью «оригинал | результат | разница»,
  dump'ом движка и сравнением с оригиналом.

## Как устроены тинт-матрицы

Движок рисует `premultiplied(текстура) × tint`. Для семейства одинаковых по рисунку
изображений `X_c` (c — цвет) ищется матрица `M` и цвета `t_c`, минимизирующие
`Σ ||X_c − t_c·M||²` — это разложение ранга 1 (главный собственный вектор матрицы
Грама). Все расчёты идут в premultiplied RGB, как у движка.

Варианты, которые строит `abtint.py build`:

| Модель | Смысл |
|---|---|
| `grey` | одна серая матрица, цвет целиком в `tint` |
| `rgb` | своя матрица на каждый канал (точнее, если оттенок пятен различается) |
| веса `plain` / `equal` / `minimax` | обычная ошибка / равный вклад цветов / итеративно подтягивает худший цвет |
| группы (`plan-k2`) | цвета семейства делятся на 2 группы по лучшему разбиению, у каждой своя матрица |
| `additive` | 2 слоя: нетинтованная основа + аддитивное тинтованное свечение (лава-декали) |

`tint` может только затемнять, поэтому матрица нормируется в светлую область
(самый яркий цвет получает `tint` около 1).

`select.py` выбирает для каждого семейства вариант с минимумом файлов, у которого
худший цвет даёт PSNR ≥ 36 дБ и SSIM ≥ 0.95; если таких нет — лучший из вариантов
с не более чем двумя файлами. Для тайлов `additive` не используется: у тайла один слой.

Что получилось (0.8.0): 556 текстур → 84 матрицы. Ниже порога (принятая потеря):
трава grass-1/2, volcanic heat-3/4, лава-декали. Подробно — `data/selection.md`,
все варианты — `data/compare-variants.md`, отчёт 0.8.0 — `data/report-0.8.0.md`.

Не оптимизируются: снег и лёд (разные рисунки), grass-3/4 (один цвет),
деревья и камни (автор уже тинтует их сам).

## Содержимое

| Файл | Назначение |
|---|---|
| `reforge.py` | сопровождение: обновление кода и графики с upstream, установка матриц, генерация `tint-matrices.lua`, статические проверки |
| `patches.py` | список правок Reforged поверх кода upstream (якорь → замена) |
| `abtint.py` | анализ семейств (`survey`) и построение матриц (`build`) |
| `select.py` | выбор варианта на семейство, сборка итоговых матриц и `report.json` |
| `compare.py` | сводная таблица вариантов |
| `pngverify.py` | проверка PNG после оптимизации (открываются, размер, PSNR к исходнику) |
| `run_isolated.py` | изолированный запуск Factorio (dump / create / graphical) копии мода |
| `dumpdiff.py` | структурное сравнение dump'ов оригинала и Reforged |
| `atlas_estimate.py` | грубая оценка атласа по целым файлам |
| `atlas_regions.py` | оценка атласа по загружаемым областям кадров + проверка, что области не выходят за картинку |
| `economy.py` | `tint` экономного режима: одна матрица на семейство |
| `colors.py` | цвета карты и частиц против текстур, отчёт `data/colors-report.md` |
| `luacheck52.py` | синтаксис Lua 5.2 через luac 5.1 |
| `data/matrices-report.json` | для каждого семейства: исходные файлы, группы, матрицы, `tint` и метрики каждого цвета — источник `tint-matrices.lua` |
| `data/upstream-code-manifest.json` | версия и SHA-1 файлов кода upstream, поверх которых собран мод |
| `data/upstream-graphics-manifest.json` | SHA-1, размер и статус каждого файла графики upstream: `kept` (лежит в моде), `matrix` (заменён матрицей), `unused` (код его не грузит), `derived` (пересчитан инструментом Reforged) |
| `data/survey.json`, `data/plans/` | анализ семейств и планы вариантов, на которых строились матрицы |

Требования: Python 3.10+, `numpy`, `Pillow`. Запуск всегда `python -I -B путь/к/скрипту`,
пути к данным — аргументами.

## Где взять исходники upstream

Оригиналы (192 МБ графики) в мод не входят. Нужные версии скачиваются с портала
(требуется вход): `alien-biomes` (код) и `alien-biomes-graphics` (графика), см.
`data/upstream-*-manifest.json`. Распаковать каждый ZIP в свою пустую папку и передавать
путь аргументом. Совпадение с тем, на чём собран мод, проверяется по SHA-1 из манифестов
(`reforge.py graphics --upstream ...` покажет 0 изменений).

## Экономный атлас (настройка «Память под графику ландшафта»)

Startup-настройка `alien-biomes-reforged-atlas`: `normal` (по умолчанию) или `economy`.
Экономный режим не добавляет файлов — он только реже использует уже имеющиеся
(`prototypes/reforged/economy.lua`):

| Что | Как |
|---|---|
| Тайлы | одна матрица на семейство (`tint` пересчитан к ней: `tools/economy.py` → `data/economy-tints.json` → `reforge.py tintlua`), только варианты 1×1 и 8 из 16 вариантов 2×2; 4×4 — три четверти площади каждого листа — не грузятся |
| Декоративы | у декоративов этого мода с 6+ картинками остаётся каждая третья |
| Деревья | похожие виды берут графику соседа (willow→mangrove, greypine→conifer-01, specter и scarecrow→oaktapus, pear→ash), у каждого вида — первая половина вариаций, без карт нормалей |

Что сохраняется ради сохранений: имена прототипов, число вариаций каждого дерева
(лишние вариации получают графику оставшихся), тайлы и декоративы выбирают картинку по
позиции. Переключать можно на существующей карте — меняется только вид.

Оценка атласа по загружаемым областям (`tools/atlas_regions.py`, без учёта обрезки
прозрачных краёв движком): оригинал 1374 МиБ, обычный режим 710 МиБ, экономный 188 МиБ.
Проверка экономного режима: `run_isolated.py dump RUN . --set alien-biomes-reforged-atlas=economy`.

## Цвета карты и частиц

`tools/colors.py` сравнивает цвет каждого тайла на карте (`map_color` автора) и цвет частиц
групп биомов со средним цветом того, что реально рисуется (PNG × `tint`). Светлота не
учитывается — автор делает карту светлее, чтобы она читалась; расхождением считается только
другой оттенок (хроматическое расстояние CIELAB > 10). Отчёт: `data/colors-report.md`.

Результат 0.8.3: исправлять нечего. Карта: медиана расхождения 1, частицы: 2–5. Выше порога
только вулканика, и это намеренно: раскалённая heat-4 ярко выделена на карте как самая
медленная местность, а частицы — серые обломки породы, а не свечение трещин.
Тайловые `particle_tints` движок использует только для брызг воды, на суше они не нужны.
Перепроверять после замены текстур: `colors.py report DUMP tools/data/colors-report.md`.

## Процедуры

### Вышла новая версия кода Alien Biomes

```
python -I -B tools/reforge.py code --upstream ПАПКА_alien-biomes --dry-run   # что изменится
python -I -B tools/reforge.py code --upstream ПАПКА_alien-biomes
python -I -B tools/reforge.py check
```

`code` заменяет файлы upstream (Lua — всегда, с переписыванием путей
`__alien-biomes__`/`__alien-biomes-graphics__` → `__Alien-biomes-Reforged__`; остальные —
только если upstream их изменил, чтобы не затереть результат pingo), удаляет то, что
upstream удалил, заново применяет `patches.py`, переносит записи changelog Reforged
поверх нового changelog upstream и обновляет манифест. Графику, `tools/`, `info.json`
и собственные файлы Reforged не трогает.

Если якорь правки не найден, команда сообщает `PROBLEM` и код возврата 1: открыть новый
код upstream, понять, что поменялось, исправить запись в `patches.py` и повторить.

Дальше: поднять версию в `info.json`, запись в `changelog.txt`, dump
(`run_isolated.py dump`) и `dumpdiff.py` против dump'а оригинальной пары той же версии.

### Вышла новая версия графики

```
python -I -B tools/reforge.py graphics --upstream ПАПКА_alien-biomes-graphics          # отчёт
python -I -B tools/reforge.py graphics --upstream ПАПКА_alien-biomes-graphics --apply  # скопировать kept
```

- `kept` изменились — копируются как есть, потом pingo.
- `matrix` изменились — пересобрать матрицы этих семейств (следующий раздел).
- `derived` изменились — пересчитать инструментом, указанным в `data/derived-graphics.json`.
- В конце `reforge.py manifest --code ... --graphics ...` с новыми релизами.

### Пересобрать матрицы

```
python -I -B tools/abtint.py survey ПАПКА_graphics/graphics WORK/survey
python -I -B tools/abtint.py build  ПАПКА_graphics/graphics WORK/var-k2 tools/data/plans/plan-k2.json --only "^mineral"
...  (остальные планы из data/plans)
python -I -B tools/select.py WORK/final 36 0.95 k2mm=WORK/var-k2 ...
python -I -B tools/reforge.py matrices --selection WORK/final
python -I -B tools/pngverify.py . WORK/final/matrices ПАПКА_graphics   # после pingo
```

Превью для глаз — `WORK/final/previews/` (оригинал | матрица×tint | разница×4).
`plan-k2.json` задаёт группы цветов, найденные `survey` (`rgb_k2_parts`).

### Проверки перед коммитом

1. `reforge.py check --png` — пути, правки, PNG.
2. `run_isolated.py dump RUN .` — только этот мод; `dumpdiff.py` против оригинальной пары.
3. Dump всей сборки через `test-runs/_tools/factorio_check.py` (правила запуска — в
   `agent-context/procedures/TESTING.md` рабочей копии проекта).
4. Вид в игре — приёмка пользователем.
