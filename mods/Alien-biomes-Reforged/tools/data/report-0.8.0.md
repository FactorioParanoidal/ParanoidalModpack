# Alien-biomes-Reforged — отчёт (2026-10-16)

> Исторический отчёт сборки 0.8.0. Пути `work/...` относятся к временной рабочей папке, которой больше нет; данные из неё перенесены в `tools/data/`.

## Что сделано
- `Alien-biomes-Reforged/` — объединённый мод (код alien-biomes 0.7.4 + графика alien-biomes-graphics 0.7.1), версия 0.8.0.
  Конфликтует с `alien-biomes` и `alien-biomes-graphics` (`!` в info.json).
- Исходные папки `alien-biomes_0.7.4/` и `alien-biomes-graphics_0.7.1/` не тронуты — эталон для сравнения.
- Цветовые семейства заменены матрицами + tint (556 файлов → 84 матрицы):
  - минералы dirt-1…6 / sand-1…3 (12 цветов): по 2 матрицы на семейство, sand-1 — 1;
  - volcanic heat-1 — 1 матрица, heat-2…4 — по 2 (пары blue+purple / green+orange);
  - трава grass-1/2 (10 цветов) — по 2 матрицы;
  - дюны (30 форм × 12 цветов) — по 1 матрице на форму, tint в спрайте;
  - лава-декали (13 активных × 4 цвета) — 2 слоя: нетинтованный камень + аддитивное тинтованное свечение.
- Не оптимизируются: снег/лёд (разные рисунки), grass-3/4 (один цвет), деревья/камни (уже тинтуются автором).
- Удалены неиспользуемые файлы: 68 спрайтов лавы, закомментированных в коде; скалы (замена скал выключена в оригинале); green-coral.

## Выбор вариантов
Для каждого семейства построены 7 вариантов (grey / rgb / rgb-equal / rgb-minimax, 2 матрицы minimax / plain,
двухслойная схема для декалей). Правило: минимум матриц при худшем цвете PSNR ≥ 36 дБ и SSIM ≥ 0.95,
иначе лучший из вариантов с ≤ 2 матрицами. Таблицы: `work/final/selection.md`, все варианты — `work/compare-variants.md`,
превью «оригинал | матрица×tint | разница×4» — `work/final/previews/`.

Ниже порога (принятая потеря): grass-1/2 (худший PSNR ~31, теряются бурые/оранжевые пятна между травой),
volcanic heat-3/4 (33.5 / 31.2 дБ: камень слегка окрашен, свечение менее насыщено), лава-декали (28–35 дБ, SSIM ≥ 0.98).
