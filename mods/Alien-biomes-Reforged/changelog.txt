Version: 0.8.4
Date: 16. 10. 2026
  Features:
    - Geology by soil colour (startup setting, on by default): with Resource Spawner Overhaul, new regions favour (weight x2) the ore matching the soil colour: sapphirite on blue/purple/aubergine/violet/mauve, jivolite on cream/yellow/tan, stiratite on green/olive/turquoise, crotinnium on grey/white, rubyte on red/dustyrose/orange, bobmonium on brown/beige, coal on black, oil, gas and fissures on volcanic ground. Infinite ores follow their ore. No resource disappears; the starting area is unchanged.
    - Remote interface alien-biomes-reforged / geology_bias(surface_name, tile_names) for resource generators.
  Info:
    - Unit test tools/test_geology.lua.

Version: 0.8.3
Date: 16. 10. 2026
  Info:
    - Map colours and biome particle colours were checked against the rendered textures (tools/colors.py, report in tools/data/colors-report.md): hues match the ground (median deviation 1 for the map, 2-5 for particles), so nothing is changed. The only outliers are the volcanic tiles, deliberately bright on the map (heat-4 is the slowest terrain) with rock-grey particles.

Version: 0.8.2
Date: 16. 10. 2026
  Features:
    - New startup setting "Terrain graphics memory" (alien-biomes-reforged-atlas): Normal (default) or Economy for graphics cards with little memory.
    - Economy uses only the graphics already in the mod: one tint matrix per terrain family (tints refitted, tools/economy.py), 1x1 and half of the 2x2 tile variants, every third picture of decoratives with many shapes, similar tree species share graphics (willow to mangrove, greypine to conifer, specter and scarecrow to oaktapus, pear to ash), half of the tree variations, no tree normal maps.
    - Tree variation counts and all prototype names are unchanged, so the setting can be switched on an existing map; only the look changes.
  Info:
    - Estimated atlas of the mod by loaded regions (tools/atlas_regions.py): normal 710 MiB, economy 188 MiB (original Alien Biomes 1374 MiB).

Date: 16. 10. 2026
  Info:
    - Maintenance tools and source data are kept inside the mod in tools/ (see tools/README.md): matrix builder, variant selection, checks, isolated test launches.
    - New tools/reforge.py: refreshes the code from a new Alien Biomes release and re-applies the Reforged patches (tools/patches.py) without touching optimised graphics; compares a new graphics release with the recorded upstream manifest; regenerates prototypes/tint-matrices.lua.
    - Upstream manifests (versions and SHA-1 of the files the mod is built on) are recorded in tools/data.

Version: 0.8.0
Date: 16. 10. 2026
  Info:
    - Merged Alien Biomes 0.7.4 and Alien Biomes Graphics 0.7.1 into Alien-biomes-Reforged.
  Optimizations:
    - Dirt, sand, grass and volcanic tiles use shared tint matrices with per-tile tint instead of one texture per colour.
    - Sand dune decals use one tinted matrix per shape instead of twelve coloured copies.
    - Lava decals use an untinted base layer plus an additive tinted glow layer instead of four coloured copies.
    - Removed graphics replaced by matrices and sprites the code never loads: unused lava decals, cliffs (cliff replacement is disabled upstream) and green coral.
