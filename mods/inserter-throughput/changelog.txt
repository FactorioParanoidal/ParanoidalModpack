Version: 0.1.6
Date: 21. 10. 2024
  Changes:
    - Updated for Factorio 2.0. This is a transitory update to make the mod functional. There will be another update to account for the changed inserter mechanics. Meanwhile, as always, the stopwatch command remains the ultimate arbiter on inserter throughput and will report the correct number.
  Gui:
    - Changed the toggle button to use the built-in toggle capability of buttons.
  Optimizations:
    - Paranoidal: on_tick is registered only while an /it-stopwatch measurement runs; before, it ran every tick for nothing.
  Bugfixes:
    - Paranoidal: on_configuration_changed is no longer a leaked global function.
    - Paranoidal: the throughput text is recomputed when the hovered inserter is rotated, gets pasted settings or has its positions changed by bobinserters; before, it showed the value from the moment of hovering.
    - Paranoidal: a removed player's text record is dropped.
    - Paranoidal: removed a dead branch of /it-stopwatch that called the undefined populate_name_blacklist.
  Compatibility:
    - Paranoidal port to Factorio 2.1: factorio_version set to 2.1.
