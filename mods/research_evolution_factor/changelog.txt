---------------------------------------------------------------------------------------------------
Version: 1.1.5
Date: 2026. 10. 15
  Graphics:
    - Added thumbnail.png (144x144): the picture of the mod in the mod list, made from the mod and base game graphics.
  Bugfixes:
    - Science packs again raise evolution: research ingredients are read in the 2.0 form {name, amount}; before, only the constant 0.15% per technology was added, so the whole tree gave about 85% instead of nearly 100%.
    - Research by script or command counts like ordinary research (the by_script check never worked; now it is removed on purpose).
    - Removed the top-level reset of storage and the record of started infinite research; the cost of every finished level is computed from the technology itself.
  Changes:
    - Paranoidal: Rocket failure revision 1-7 (RocketExplosions2) never raise evolution and have no evolution tooltip (prefix rocket-failure-revision in ignored_prefixes); evolution already counted for them is taken back once on load (ignore_revision 2).
    - Paranoidal: slower evolution from research: 0.12% per technology (was 0.15%) and 0.15% per 1000 science packs (was 0.35%). The whole tree up to chemical science now gives about 75% evolution instead of about 90%. Evolution already gained in a save is not changed.
    - Paranoidal: the upgrade chains of paranoidal-upgrade-tech (research-efficiency-*, worker-robot-battery-*) never raise evolution and have no evolution tooltip, whatever the settings. Set by name prefix in parameters.lua (ignored_prefixes); the path_increment estimate skips them too.
    - Paranoidal: also never raise evolution and have no evolution tooltip: Flight recorder decoding, Inserter capacity bonus 1-4, Bulk inserter capacity bonus 1-8, Inserter length 1-2, Inserter offset, Full inserter 1-2, Toolbelt 1-13, the six electric loaders and Braking force (all levels). Exact names are set in parameters.lua (ignored_names).
    - Paranoidal: evolution already counted for technologies that became ignored is taken back on load (also for the upgrade chains above), by the current technology cost; the player gets a chat message with the old and new evolution. Runs on every configuration change and once after parameters.lua ignore_revision is raised.
    - The "ignore infinite technologies" setting ignores only technologies with a cost formula and more than 10 levels (infinite or not); count_formula technologies with up to 10 levels (e.g. research-speed-7, worker-robots-battery-1) now raise evolution and show their value.
    - The tooltip is built by evolution-label.lua; mods that change technology costs after this mod's data-final-fixes call relabel_all again so the tooltip matches the final cost.
    - The tooltip "ignore infinite" check now reads unit.count_formula (it never matched before, so ignored technologies showed "some value").
    - Values are rounded to 3 significant digits; technologies whose level costs differ show a per-level range; research_trigger technologies show the constant part.
    - The tooltip says the percent applies to the remaining evolution up to 100%.
    - A formula technology finished without a recorded start uses its current unit count instead of 0.
    - Paranoidal: remote interface research_evolution_factor.path_increment(force_name, technology_names) returns the evolution exponent of the listed unresearched technologies by the same rule (read-only); used by paranoidal-tech-tree.
    - Paranoidal: the ten "Quality control" technologies of ic-more-qualities (ic-defect-control-1...10) together add the constant part of one technology (0.015% each instead of 0.15%); the science pack part is unchanged. The whole chain raises evolution by about 0.34% instead of 1.68%. Set by name prefix in parameters.lua (constant_scale); the tooltip shows the same value. Evolution already gained in a save is not changed.
    - Control script rewritten for the 2.0 API. Science packs are counted as the game charges them, with the map technology price multiplier (the tooltip shows the value for multiplier 1).
    - Every finished level counts once per save; levels researched several at once, by migrations or by a script without the event, are found on configuration change.
    - Evolution is raised on every surface for every AI controllable force; a new surface starts with the evolution gained from research.
    - Old saves: on the first load the evolution of enemy forces on every surface is recalculated once from the researched technologies only (time, pollution and other sources are dropped).
    - paranoidal-tech-tree estimate (path_increment) uses the same per-level rule, all remaining levels of finite multi-level technologies.
