# Ёмкость материопамяти (Fluid Memory Storage) — форк Paranoidal

Локальный форк мода [Fluid Memory Storage](https://mods.factorio.com/mod/fluid-memory-storage) 1.7.9 (автор **notnotmelon**) для сборки [Paranoidal](https://github.com/FactorioParanoidal/ParanoidalModpack). Происхождение для проверок сборки: `mods-metadata/fluid-memory-storage.json`. Пара для предметов — мод `deep-storage-unit` (Хранилище материопамяти); общие правила (энергия, скидка за качество, миграции) описаны в его README.

Спасибо notnotmelon за оба мода: изменения ниже можно забрать обратно в исходные моды.

## Как работает

Ёмкость материопамяти — резервуар 3×3 на 120 000 единиц, привязанный к одной жидкости.

- Раз в секунду мод держит в резервуаре 60 000 (половину его объёма). Излишек уходит в счётчик материопамяти, при нехватке резервуар пополняется из счётчика. Количество не ограничено.
- Ёмкость привязывается к первой жидкости, попавшей в резервуар, или к жидкости, выбранной заранее в окне. Пустую ёмкость можно отвязать кнопкой «Сбросить».
- Скрытый комбинатор передаёт в логическую сеть общее количество (не больше 2,1 млрд).
- Энергопотребление и скидка за качество — как у хранилища (жидкость считается стопками по 1000).
- При разборке содержимое и температура сохраняются в упакованной ёмкости. **При разрушении всё содержимое теряется.**

### Температура

У всего, что хранит ёмкость, одна температура (решение пользователя 2026-10-14):

- жидкость, попавшая в пустую ёмкость, сохраняет свою температуру;
- при смешивании с жидкостью другой температуры остаётся **меньшая** из температур — без средневзвешенных значений и без появления лишней энергии;
- из счётчика в резервуар жидкость возвращается с этой температурой.

Пример: в ёмкости пар 165 °C, в неё подаётся пар 500 °C — хранится 165 °C. Подаётся пар 100 °C — хранится 100 °C.

Ограничение: внутри резервуара и труб жидкость смешивает сама игра. Если в горячую ёмкость понемногу поступает холодная жидкость, температура будет снижаться ступенями по показаниям резервуара, пока не дойдёт до температуры входящей жидкости. Разницы меньше 0,01 °C (погрешность смешивания игры) не учитываются.

Раньше мод каждую секунду ещё раз подмешивал весь резервуар к счётчику, и температура уходила к температуре потока: горячий пар «нагревал» миллион хранимого за минуты, тонкая струйка холодной воды остужала его.

## Изменения 9.8.0

Полный список — `changelog.txt`.

- Новое правило температуры (см. выше), исправлен дрейф.
- Выбор жидкости заранее в окне (кнопка выбора у пустой ёмкости с пустым резервуаром) и кнопка «Сбросить» у пустой ёмкости.
- Скидка энергопотребления за качество ёмкости.
- Упакованная ёмкость с удалённой жидкостью больше не роняет игру; переименованные жидкости отслеживаются и для упакованных ёмкостей.
- Потерянные скрытые части создаются заново, ёмкость не удаляется; пропавшая без события ёмкость убирается без сообщений в чате.
- Окно закрывается, если игрок отошёл; в удалённом просмотре — только просмотр. Точное количество в подсказке, температура без «0 °C» при пустом резервуаре и без склейки «Температура: Пар:».
- Клонирование создаёт свои скрытые части (раньше — источник питания хранилища предметов) и не плодит дубли при `clone_area`.
- Изменение настройки мощности применяется сразу.
- Объём в резервуаре — половина его собственного объёма.
- События постройки, разборки и клонирования фильтруются по имени.

### Рецепт

По решению пользователя рецепту возвращены 4 энергощита, как в Beta 8 (fluid-memory-storage 1.4.6). Правка в `zzzparanoidal/final-fixes/recipies.lua`; переработка теперь возвращает 1 энергощит.

### Локализация

Русские названия по решению пользователя: «Ёмкость материопамяти», «Ёмкость материопамяти (упакованная)», «Комбинатор ёмкости материопамяти»; так же называются мод и исследование. Тексты для игры лежат в `ParanoidalLocale/locale/ru/fluid-memory-storage.locale.cfg`; конфликтующие дубли удалены из `zzzz-user-overrides.cfg`.

## Проверки

- `luac -p` (Lua 5.1) всех Lua-файлов.
- Тесты логики и окна на заглушках API в Lua 5.1 (`review/memory-storage-20261014/tests/` вне репозитория): температура (горячий и холодный поток, погрешность, пустая ёмкость, разборка), миграции, упакованные ёмкости, выбор и сброс жидкости, доступ. Это проверка логики, не движка: смешивание в резервуаре в заглушках упрощено.

- Загрузка новой карты в движке. Работа на карте, окно и температура в игре не проверены.
