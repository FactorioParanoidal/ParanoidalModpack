---------------------------------------------------------------------------------------------------
Version: 9.0.0
Date: 2026-11-01
  Major Features:
    - One mod instead of deep-storage-unit 9.8.0 (Memory Storage, Paranoidal fork of 1.6.8 by notnotmelon, with the logistic memory units after Logistic Memory Units by restjack) and fluid-memory-storage 9.8.0 (Fluid Memory Storage, Paranoidal fork of 1.7.9 by notnotmelon). Prototype, technology, recipe, setting and locale key names are unchanged; gameplay, power formula, quality discount, refused items, temperature rule, packed units and windows work as before.
  Optimizations:
    - One scheduler updates both kinds (every unit once per second, as before) instead of one per mod, and one set of build, mine, clone and GUI handlers.
    - The windows are refreshed every 2 ticks only while a player has one open; before, each mod checked every connected player every 2 ticks all game long.
    - The power source is written only when the power usage changes (the number of stored stacks), and its buffer size is not read back on every update; the power setting is read once and the quality factor of a unit is cached.
    - The Alt-mode amount is rewritten only when the rounded text changes.
    - Graphics recompressed (lossy palette, tint masks lossless).
  Changes:
    - After the completed save migrations, deep-storage-unit is no longer shipped and its optional dependency is removed. Already migrated saves keep their data in this mod; direct content transfer from unmigrated old saves now requires the removed bridge.
    - deep-storage-unit stays as a migration bridge (9.9.0): on the first load of an old save the item units are taken over with their contents. Hidden power sources and combinators already standing at a unit are taken over too, so combinator wires stay.
    - Fluid units of old saves are taken over without their counters: the fluid stored outside the tank is lost (agreed loss); the fluid in the tank stays and the unit locks to it again.
    - Old migrations of both mods are dropped (they only fixed 1.x saves of the old mods).
  Compatibility:
    - Paranoidal port to Factorio 2.1: factorio_version set to 2.1.
    - Factorio 2.1: hide_connection_info moved from the fluid box to every pipe connection (FluidBox::hide_connection_info was removed, PipeConnectionDefinition::hide_connection_info added; without it 2.1 draws connection arrows and fluid icons on these entities).
    - Factorio 2.1 runtime API: the fluid memory unit reads and filters its tank on the entity (get_fluid, set_fluid_filter, get_fluid_capacity, get_fluid_box_prototype with get_volume) and moves fluid with extract_fluid (LuaEntity::fluidbox was removed, remove_fluid{} was renamed).
