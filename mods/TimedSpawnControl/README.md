# TimedSpawnControl — локальный порт Paranoidal

Этот мод основан на **TimedSpawnControl 1.1.0** автора **Maxikaaz** из пользовательской Paranoidal Beta 8. Сам TimedSpawnControl основан на **Spawn Control** автора **Fentus**.

Страница TimedSpawnControl на Mod Portal указывает лицензию **The Unlicense (Public Domain)**. Страница исходного Spawn Control указывает **Beerware**. Обе лицензии допускают локальную адаптацию и распространение; текст The Unlicense включён в `LICENSE`.

Порт сохраняет установку личной точки возрождения и двухэтапный поиск свободного места для функции «Я застрял». По требованиям Paranoidal случайное возрождение и пользовательские настройки удалены, а задержка установки точки зафиксирована на 60 секундах.
