# Paranoidal Rain 9.0.0

Погода для Наувиса. Форк Dynamic Rain 1.2.0 (valertron, MIT) под Factorio 2.0 с находками Real Rain 1.2.15
(Squishy1870); авторы ресурсов — `CREDITS.md`. Все настройки — карты (`prain-*`), кроме «Показывать дождь» (у игрока).

## Устройство (`control.lua` + `scripts/`)

| Модуль | Назначение |
|---|---|
| `config` | Снимок настроек `storage.cfg`; читаются только свои (`prain-`) |
| `surfaces` | Поверхности с дождём (по умолчанию `nauvis`), никогда — космические платформы |
| `players` | Игроки по поверхностям (раз в тик), скрытие дождя игроком |
| `weather` | Сухо/дождь в реальных минутах; стадии морось → дождь → ливень → гроза → муссон; первые 30–60 мин карты сухо; событие `on_phase_changed` |
| `visual` | Капли (3 слоя, ветер и порывы), брызги и круги на воде, лужи после дождя; общий предел капель за тик |
| `sound` | Петля дождя: скрытый громкоговоритель на поверхность и силу, перезапуск после загрузки |
| `thunder` | События грозы по площади карты, «волне активности», темноте и стадии; вспышки; гром со скоростью звука, раскаты |
| `lightning` | Удары молний: выбор цели по приоритетам, эффекты, разряд по цепочке; **[2.0]** удар скриптом, **[2.1]** движковый вариант закомментирован |
| `fire` | Дождь гасит обычный огонь волнами от краёв (большой — за 30 с), с паром; кислоту врагов смывает за 0,5–2 с |
| `combat` | В дождь урон огнём и кислотой врагов ×0, огнём игроков (огнемёты, турели, вагон) ×0,5 |
| `solar` | Свойство поверхности `solar-power` в дождь — 75 % от значения до дождя, потом точно восстанавливается |
| `pollution` | Вымывание загрязнения по чанкам |
| `chunks`, `jobs` | Счётчик чанков для частоты грозы; отложенные задачи по тикам |
| `dark` | Затемнение в дождь (по стадии, до 28 % в муссон) и белая вспышка экрана от близкой молнии (у игрока отключается) |
| `enemies` | В дождь враги сильнее: укусы и плевки +15 % днём, +25 % ночью; нападают чаще |
| `rods` | Точка подключения громоотводов других модов |
| `forecast` | Прогноз погоды сети радаров после технологии «Прогноз погоды» |

## Молнии в 2.0

Движковая молния (`LightningPrototype`, `LuaSurface::execute_lightning`) в 2.0 помечена как Space Age и требует
флага `space_travel_required`, который меняет всю игру. Поэтому в 2.0 удар делает скрипт: цель — самая
«притягательная» сущность в радиусе 18 клеток (приоритеты Dynamic Rain: высокие постройки, опоры, радары,
деревья, трубы, существа; `prototypes/lightning-targets.lua` → mod-data), рисуются луч с неба, вспышка и разряды
Space Age (`prain-lightning-*`), свет и тряска камеры. Вариант 2.1 (движковая молния) — в закомментированных блоках
`[2.1]` в `data-final-fixes.lua` и `scripts/lightning.lua`.

Эффекты удара: энергия цели обнуляется; опора — перегрузка сети на 3 с; радар — отключён на 20 с; роботы —
уничтожены; персонажи (не в транспорте, не в первые 60 мин), кусаки, гнёзда, черви — 50 % гибель, иначе 10 %
здоровья; деревья обожжены; рыба — сырая рыба. Дерево, деревянное и трубы с горючим загораются
(`prain-lightning-fire`, дождь его не тушит). Резервуары и склады боеприпасов (сундуки, вагоны, машины, турели и
артиллерия) передаются `paranoidal-flammable-fluids` (remote `ignite_tank`, `cook_off`): перегрев, детонация.
Бочка с водой (`zzzparanoidal-start-bnl`) тушит любой огонь, перегрев и детонацию в радиусе 2.

## Связь с другими модами

- **paranoidal-flammable-fluids**: remote `paranoidal-rain.hazard_slowdown(surface_index)`; в дождь перегрев
  резервуара, огонь по трубам и детонация идут в 2,5 раза медленнее; их огонь (`oil-fire-flame`, `flo-*`) дождь
  не тушит — только пожарные турели.
- **RampantFixed** и другие враги: кислотные и огненные лужи смываются, урон огнём и кислотой — 0 %.
- **zzzparanoidal-start-bnl**: первые 30–60 мин сухо; пожары обломков — скриптовые, дождь их не трогает.
- Огонь любого мода получает метку создания (`prain-fire-marker`) в `data-final-fixes`; моды, создающие огонь
  поздно, стоят в необязательных зависимостях.

## Погода по плану и сезоны

Дожди планируются на 4 игровых дня вперёд (`w.plan`), прогноз только читает план. С NightBrightness (настройка
`prain-seasons`): зимой дождей нет, летом — одна попытка с вероятностью 10 % за всё лето, весной и осенью — обычно;
осенний дождь кончается до зимы. Команды и `start_phase` перекрывают план.

## Прогноз погоды

Технология `prain-weather-forecast` (после `bob-radar-2`, 50 красных и 50 зелёных пакетов). На рассвете первого и
среднего дня сезона (без сезонов — каждый третий день) сила получает одну строку о днях до следующего прогноза:
ясно / дождь / буря. Достоверность p — по работающим радарам силы на поверхности: `radar` 1 очко, `bob-radar-N` — N,
1 очко → 10 %, 10 → 50 %, 100 → 100 %. Слово «маловероятно / вероятно / точно» показывает p. С вероятностью 1 − p
прогноз врёт: обещает то, чего точно не будет.

## Громоотводы (точка подключения)

Мод с громоотводом на стадии data / data-updates:

```lua
data.raw["mod-data"]["paranoidal-rain-attractors"].data.attractors["my-rod"] = {
  range = 12, priority = 1000,
  mode = "absorb",     -- "attract": принимает удар, теряет self_damage, короткий разряд идёт дальше; "absorb": гасит удар
  self_damage = 0,     -- доля макс. здоровья за удар
  energy_share = 0,    -- доля энергии удара (1000 МДж, как у молнии Space Age) в электрический буфер громоотвода
}
```

Тиры сборки: 1 — `attract` + `self_damage`; 2 — `absorb`; 3 — `absorb` + `energy_share`; 4 — больше `range` и
`energy_share`. Каждый удар вызывает событие `on_lightning_strike` {surface_index, position, target, attractor,
energy}. В 2.1 те же поля ложатся на `LightningAttractorPrototype` (`range_elongation`, `efficiency`).

## Remote `paranoidal-rain`

`is_raining(i)`, `stage(i)`, `time_left(i)`, `hazard_slowdown(i)`, `start_phase(i, "wet"|"dry", ticks, options)`
(options: `intensity`, `thunderstorm`, `fire_quench`, `pollution_cleanup_per_minute`,
`pollution_max_chunks_per_tick`), `get_events()` → `on_phase_changed`, `on_rain_pollution_cleaned`,
`on_lightning_strike`.

Команда: `/prain status | rain [мин] | dry [мин] | stage <стадия> [мин] | strike` (в мультиплеере менять погоду
могут только администраторы).
