Version: 2.1.4
Date: 31.01.2026
  Bugfixes:
    - Potential fix that inserters in a modded environment are no longer cleaned up.
    - Paranoidal: "delete all marks" clears marks on every surface, not only game.surfaces[1].
    - Paranoidal: multiplayer desync risk removed. The shortcut and the marks were synced on the first tick of every session from a module-local flag, so a joining client changed the shortcut of player 1 and created or removed marks while the host did not. They are now synced in on_init, on_configuration_changed and when the settings change; the selector setting updates the shortcut of every player.
    - Paranoidal: a setting changed by a script (without a player) updates the cached value too; before, the host kept the old value while a joining client read the new one.
    - Paranoidal: deselecting inserters (alt-selection) before any inserter was ever selected no longer errors on the missing inserter list.
    - Paranoidal: turning marks on skips an inserter that was removed but is still in the list (it is dropped by the next parse) instead of erroring.
    - Paranoidal: "Train: Extend area to clean up in length" (PI_extend_length) for vertical cargo wagons moved the top edge of the search area down (sign error), so the area shrank instead of growing.
    - Paranoidal: "General: Unblock locked chest slots" (PI_temp_unlock) never lifted the bar of a cargo wagon (wagons were handled by the mining-drill branch first); inventories without a bar are no longer touched.
    - Paranoidal: a listed inserter that is mined, destroyed or removed by a script leaves the list with its mark at once; before, the mark stayed until the list cursor reached it.
    - Paranoidal: removed the leaked global variables stack, myBeltLine and PI_inserters.
    - Paranoidal: the inserter mark (PI_mark) is hidden, so the list of turret priority targets no longer offers it (as a simple entity with force it counted as a military target). The marks are created, drawn and removed as before.
    - Paranoidal: with "General: Delete items" on, the hand is no longer destroyed for pickup entities the mod did not know: underground belts, splitters, loaders and linked belts get the stack back on any of their transport lines; infinity, linked and proxy containers like chests; spider vehicles into the trunk; items on the ground are spilled back (plain items only); any other entity into its output inventory or the burnt result inventory of its burner. Items are destroyed only when nothing could take them, as before. Inventory numbers replaced by defines.inventory.
    - Paranoidal: putting a stack back on a belt one item at a time created fresh items; an item with health, spoilage, durability, ammo or other data is now put back only as the whole held stack, so partly used magazines and tools are not refilled.
    - Paranoidal: a train that leaves a station empty also gets its unloading inserters cleaned (upstream skipped trains without cargo).
    - Paranoidal: a listed inserter moved with the dollies (paranoidal-picker-tools, interface PickerDollies) takes its mark along; moved as a clone, the clone takes its place in the list.
    - Paranoidal: listed inserters are registered with register_on_object_destroyed, so upgrades and removal without an event also drop the entry and its mark at once (replaces the mined/died/script_raised_destroy handlers); entries of older saves are registered on configuration change or by the list cycle.
    - Paranoidal: removed the leaked global variables print_debug, PI_checkInserterIsStuck, PI_db_inserters and PI_db_internal.
  Optimizations:
    - Paranoidal: on_tick is registered only while the inserter list has entries (in Paranoidal the selector is off by default, so it ran every tick for nothing); the list is no longer read from and written back to storage every tick.
    - Paranoidal: on_train_changed_state is registered only while "Train: Clean up inserters at train stops" is on (off in Paranoidal); before, every state change of every train called the mod.
    - Paranoidal: selecting checks duplicates by unit number instead of walking the whole list for every inserter; deselecting removes all selected inserters in one pass; a removed entry is replaced by the last one instead of shifting the list.
    - Paranoidal: a train leaving a station is checked with get_item_count instead of building its full contents table; the stuck check reads status, held stack and positions once.
    - Paranoidal: saves keep their inserter list; the unit-number index is built from it on first use, no migration needed.
  Compatibility:
    - Paranoidal Space Age branch: no optional dependency on space-age, so with Space Age enabled the mod loads in the same order as without it; paranoidal-space-age-filter hides the expansion from it in any case.
    - Paranoidal port to Factorio 2.1: factorio_version set to 2.1.
    - Paranoidal port to Factorio 2.1: defines.inventory.assembling_machine_*, furnace_* and rocket_silo_input/output/modules replaced by defines.inventory.crafter_input/output/modules/trash.
