# Picklocks Inserter (локальный форк Paranoidal)

Исходный мод — [Picklocks Inserter block detacher](https://mods.factorio.com/mod/Picks-Inserter) (автор Picklock). Освобождает застрявшие манипуляторы: выбранные планировщиком и стоящие у отправляющегося поезда. В Paranoidal по умолчанию планировщик и поездной режим выключены (`zzzparanoidal/settings-final-fixes.lua`).

Изменения сборки описаны в `changelog.txt` (строки «Paranoidal»). Главное, версия 2.1.4:

- `on_tick` регистрируется, только пока в списке выбранных манипуляторов что-то есть; при пустом списке мод не работает каждый тик.
- Список ведётся с индексом по `unit_number` (`storage.PI_db_set`): выбор и снятие выбора без перебора всего списка для каждого манипулятора, удаление без сдвига.
- Снесённый, уничтоженный или удалённый скриптом манипулятор сразу уходит из списка вместе с меткой.
- Исправлены расширение зоны вдоль вертикального вагона (ошибка знака) и снятие блокировки слотов у грузового вагона (ветка была недостижима).
- Сохранения совместимы: индекс строится из существующего списка при первом использовании.
