Version: 8.1.31
  Changes:
    - Automatic-Cursed-FMD 9.0.0 is integrated into zzzparanoidal, replacing Cursed-FMD: solid-resource drills with a process-fluid input automatically select one resource matching that fluid through native filters. Empty pipes retain the last fluid; exhaustion selects the next matching resource. Dry ores are selected only before any fluid has been identified. Fuel fluid is excluded, fluid-output extractors are unchanged, and filter changes never replace drills or delete fluids. Registered drills are checked over a 120-tick wheel; depletion wakes nearby managed drills on the next tick, before AutoDeconstruct checks them. Init/configuration changes register existing drills. No Cursed-FMD migration is shipped: the attempted JSON rename preserved entity state but left some dry-only variants unable to resume wet mining. Remove filtered drills in the old build before updating an important save; without the old prototypes these variants disappear.
    - Automatic-Cursed-FMD respects a manual drill filter: any filter other than the one it applied (another ore, blacklist mode, extra slots, pasted or blueprinted settings) is left untouched, so the player can choose between ores sharing one fluid. Clearing the filter returns the drill to automatic selection.
    - Added an isolated, optional liquid fuel balance for flamethrower turrets, Hero ranks and the flamethrower wagon: six explicit fuels including diesel, damage multipliers from the agreed final fuel values; all nine gases from the source fuel list are excluded. Native streams, fire, target burning, refuelling, timing and research handle combat without Lua shot or hit handlers. Disabling the startup setting restores the source fuel lists and multipliers. Save migration clears only unsupported internal fuel and preserves external pipes and existing turrets.
