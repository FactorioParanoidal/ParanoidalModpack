Version: 8.1.28
  Compatibility:
    - Paranoidal port to Factorio 2.1: factorio_version set to 2.1.
    - Paranoidal port to Factorio 2.1: assembler pipe pictures are taken from __base__/prototypes/entity/assembler-pictures.lua (2.1 removed the global assembler2pipepictures/assembler3pipepictures and assemblerpipes.lua).
    - Paranoidal port to Factorio 2.1: battery electric locomotive and wagon no longer set crash_trigger (2.1 removed the base global crash_trigger(); it was a silent sound).
    - Paranoidal port to Factorio 2.1: recycling recipe generation and recycling icons are taken from the built-in recycler mod (__recycler__/recycling.lua, __recycler__/graphics/icons/); recycling code checks mods["recycler"] instead of mods["quality"].
    - Paranoidal port to Factorio 2.1: science pack checks accept every item type (2.1 vanilla science packs are plain items, mod packs may stay tools).
    - Paranoidal port to Factorio 2.1: the Beta 8 icon list addresses the vanilla science packs as items (they were tools in 2.0).
    - Paranoidal port to Factorio 2.1: defines.inventory.assembling_machine_*, furnace_* and rocket_silo_input/output/modules replaced by defines.inventory.crafter_input/output/modules/trash.
    - Paranoidal port to Factorio 2.1: the recycling rebuild reads recipe categories as a list (the first is the former main category) and independent_probability; rebuilt recycling recipes stay available from the start as in 2.0 (the 2.1 generator locks them behind the recycling technology), and the hidden recycling unlocks (also those left by removed recipes) are dropped from technologies.
    - Paranoidal port to Factorio 2.1: recipes use categories (RecipePrototype::category and additional_categories were merged into categories; the first entry keeps the meaning of the former main category, a changed main category keeps the other entries).
    - Paranoidal port to Factorio 2.1: recipe category changes go through bobmods.lib.recipe.set_main_category/get_category; the Beta 8 energy data still uses the 2.0 names and is converted on apply (category -> categories[1], fuel_category -> fuel_categories); fuel barrels use fuel_categories.
    - Paranoidal port to Factorio 2.1: the recipe category basic-crafting (removed from the 2.1 base game) is kept: it is created and given back to the vanilla assembling machines 1-3 as in 2.0 (mining drill bits).
    - Paranoidal port to Factorio 2.1: the recycling rebuild replaces only pure recycling recipes (every category recycling), as 2.0 replaced only category recycling; scrap recycling (recycling + hand-crafting) stays.
    - Paranoidal port to Factorio 2.1: product probability renamed to independent_probability (recipe results, minable results, generated products).
    - Paranoidal port to Factorio 2.1: loot entries use the 2.1 format (type, name, amount_min, amount_max, independent_probability instead of item, count_min, count_max, probability).
    - Paranoidal port to Factorio 2.1: items use fuel_categories (ItemPrototype::fuel_category was removed).
    - Factorio 2.1 quality tips: the simulations roll further tiers with chain_probability of the tier reached (2.1; the 2.0 next_probability), show the module effect as it is (2.0 showed it divided by 10) and the ladder column "upgrade chance" is chain_probability, so the tips texts (effect x 10 x upgrade chance 0.204 ...) stay right.
    - Factorio 2.1: removed tweaks/custom/uniform-recipies.lua and the recipe fields always_show_products/show_amount_in_title of the Beta 8 data (removed in 2.1, silently ignored); the wooden pipe sets hide_connection_info on its pipe connections (moved there from the fluid box); the loader counterpart rows of a deconstruction planner are appended after its last filter (2.1 filter counts are dynamic: entity_filter_count is the highest used index, engine probe test-runs/port21-decon-20261102; the 2.0 code saw a planner without holes as full).
    - Factorio 2.1 (Paranoidal decision D30 A): every assembling machine and furnace with fluid boxes can be flipped as in 2.0 (use_mirroring = true unless the machine sets it, tweaks/entity/crafting-machine-mirroring.lua).
    - Factorio 2.1 graphics: the torch flame uses the 2.0 refinery fire kept in angelspetrochemgraphics (the base file was removed in 2.1).
