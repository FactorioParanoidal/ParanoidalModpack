# Модульное ядро Beta 8

`data.lua` — значения прототипов из согласованного итогового снимка Beta 8 (normal), а не стандартные определения Bob's Modules. `integration.lua` — модульные входы потребителей, зависимости исследований, категории изготовления и ограничения продуктивности. Подключение — `prototypes/modules-beta8.lua` после общих финальных преобразований сборки.

## Преобразования для Factorio 2.0

- Общие предметы сохраняют используемые сборкой ID (`bob-*`, `efficiency-*`). Отсутствующие Raw, Green и квантовые линейки имеют отдельные ID; сжатие восьми тиров в пять не применяется.
- Исследовательские детали снова имеют тип `tool` и расходуются лабораторией модулей.
- Эффекты сохраняют **фактический результат Factorio 1.1.107**. Парсеры двух движков по-разному обрабатывают некоторые дробные проценты. Малое смещение 0.00001 внутрь целевого процентного интервала предотвращает потерю одного процентного пункта при преобразовании в fixed-point в 2.0. Это не дополнительный игровой бонус; runtime-эффекты сравнены с измеренным эталоном.
- Старые `module.limitation` переносятся в `recipe.allow_productivity` и `recipe.allowed_module_categories`. God и обычные/Raw сохраняют разные списки.
- Маяки используют линейный `profile={1}` вместо зависимости эффективности от количества маяков в 2.0. Графические HR-слои раскрыты в основной формат спрайтов.
- Графика скопирована в собственное пространство имён. Исходные моды/пути и SHA-256 перечислены в `provenance.json`.

## Граница этой пачки

Это ядро переноса, не завершённое восстановление всей связанной системы. Отсутствующие машины Schall, паровой сборщик, полная ресурсная достижимость, предел продуктивности 2.0 и визуальная/эксплуатационная приёмка требуют отдельного завершения. Совместимость со старыми сохранениями не обещается.
