# Баланс жидкого топлива огнемётов

Единственный реестр — `config.lua`: имя жидкости, необязательные `efficiency` (по умолчанию1) и `enabled` (по умолчаниюtrue). Источник энергии — окончательный `fluid.fuel_value` после energy-port; опорная энергия560000Дж фиксирована. Добавление топлива не перенормирует остальные.

`data.lua` меняет только допуск/множители нативных атак и описания. Родные stream/fire/sticker, геометрия, расход, частота, сроки, подпитка и исследования остаются движку. Все топлива используют общие нативные сроки. Никакие боевые события не подписываются.

`control.lua` вызывается только при init/configuration_changed: убирает несовместимую жидкость из внутреннего накопителя и удаляет кэш прежнего экспериментального обработчика. Содержимое внешнего трубного fluidbox и сами постройки сохраняются.

## Отключение и удаление

В настройках запуска модов выключить «Огнемёты: баланс жидкого топлива» и перезапустить игру. Восстановятся исходные допуск и множители сборки; при загрузке сохранения неподдерживаемый дизель будет удалён только из внутреннего накопителя, внешний буфер останется.

Для полного удаления убрать require в `settings.lua`, `data-final-fixes.lua`, require и два вызова `sync` в `control.lua`, затем этот каталог и `locale/{ru,en}/flame-fuels.cfg`. Согласованные рецепты и теплотворность фича не изменяет. После удаления Factorio обработает несовместимый внутренний буфер по обычным правилам; для сохранения с дизелем сначала удобнее загрузить игру с выключенной настройкой.

## Расширение

Текущий список содержит шесть выбранных жидких топлив. Девять газовых прототипов исходного допуска, включая метанол, этанол и гидразин, исключены. Добавление другого топлива требует одной записи в `config.fuels`; положительный `fuel_value` сам по себе не даёт допуска. Разные сроки по топливам не имитируются: будущая реализация должна отдельно доказать совместимость и стоимость обновления. Интерфейс metadata `paranoidal-flamethrower-fuels` содержит фактический режим, исходный допуск и вычисленные значения для проверок/отчёта.
