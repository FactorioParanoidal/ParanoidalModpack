# Архив эксперимента Visible Pollutants 9.5.0

Здесь сохранены только 17 новых/изменённых файлов версии 9.5.0 относительно 9.4.6, включая последнее исправление видимости (128 тайлов). Это исходники для дальнейшей работы, а не самостоятельный мод. Не подключать require из этой папки.

Активные файлы уровнем выше побайтно восстановлены из Git e90f5aefefaca9a3e76fd63091b6b8a2c0fd0cb3 (9.4.6). Исходный commit эксперимента: e7193f786; последнее состояние: d30eddf1a3b8f3cbcc25924f75c54c798be81ba0. Проверочные SHA-256 и базовая версия перечислены в manifest.json.

Для восстановления полного эксперимента нужна отдельная копия базовых файлов 9.4.6 с наложением этих 17 файлов; не накладывать архив на рабочую игру без отдельного решения. Пять новых PNG, анимация, motion-настройка и новый scheduler сейчас не подключены.

Дальнейшее направление: сохранить полезное покрытие отдалённой камеры отдельной минимальной правкой старой основы; графические опыты возобновлять с одной формы и наглядного сравнения при приемлемой нагрузке, не с новой полной перестройки.
